# Breast Cancer Wisconsin (Diagnostic) Dataset

## Overview
The Breast Cancer Wisconsin (Diagnostic) Dataset contains measurements computed from digitized images of fine needle aspirates (FNA) of breast masses. It is used to classify tumors as malignant or benign.

## Source
UCI Machine Learning Repository

https://archive.ics.uci.edu/dataset/17/breast+cancer+wisconsin+diagnostic
