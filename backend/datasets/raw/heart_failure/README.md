# Heart Failure Clinical Records Dataset

## Overview
The Heart Failure Clinical Records Dataset contains medical records of patients with heart failure. It is commonly used to predict survival using clinical features.

## Source
UCI Machine Learning Repository

https://archive.ics.uci.edu/dataset/519/heart+failure+clinical+records

## Disease
Heart Failure

## Data File
data.csv

## Target Column
DEATH_EVENT

## Number of Samples
299

## Number of Features
12

## Features
- age
- anaemia
- creatinine_phosphokinase
- diabetes
- ejection_fraction
- high_blood_pressure
- platelets
- serum_creatinine
- serum_sodium
- sex
- smoking
- time

## Class Labels
- 0 = Survived
- 1 = Death Event

## Missing Values
No
