# Parkinsons Dataset

## Overview
The Parkinsons Dataset contains biomedical voice measurements from people with and without Parkinson's disease. The dataset is commonly used for binary classification tasks.

## Source
UCI Machine Learning Repository

https://archive.ics.uci.edu/dataset/174/parkinsons

## Disease
Parkinson's Disease

## Data File
data.csv

## Target Column
status

## Number of Samples
195

## Number of Features
22

## Features
The dataset contains voice measurement features such as:
- MDVP:Fo(Hz)
- MDVP:Fhi(Hz)
- MDVP:Flo(Hz)
- Jitter
- Shimmer
- NHR
- HNR
- RPDE
- DFA
- PPE
and other biomedical voice measurements.

## Class Labels
- 0 = Healthy
- 1 = Parkinson's Disease

## Missing Values
No
