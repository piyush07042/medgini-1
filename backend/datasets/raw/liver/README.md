# Indian Liver Patient Dataset (ILPD)

## Overview
The Indian Liver Patient Dataset (ILPD) contains clinical records collected from patients in India. It is designed for binary classification to determine whether a patient has liver disease.

## Source
UCI Machine Learning Repository

https://archive.ics.uci.edu/dataset/225/ilpd+indian+liver+patient+dataset

## Disease
Liver Disease

## Data File
data.csv

## Target Column
Dataset

## Number of Samples
583

## Number of Features
10

## Features
- Age
- Gender
- Total Bilirubin
- Direct Bilirubin
- Alkaline Phosphotase
- Alamine Aminotransferase
- Aspartate Aminotransferase
- Total Proteins
- Albumin
- Albumin and Globulin Ratio

## Class Labels
- 1 = Liver Disease
- 2 = No Liver Disease

## Missing Values
Yes (Albumin and Globulin Ratio contains a few missing values.)
